# Steady — Recovery Companion (Step 1 / Warm-up)

A GenAI-powered check-in and personal emergency script for people navigating
substance use recovery in India. Built for the PromptWars (hack2skill) "Build
with AI" challenge — this repo is the **warm-up Step 1**: a minimal but real,
end-to-end slice that the 3-hour main challenge builds on directly.

## Persona

**Primary persona: the person in recovery.** Every screen, prompt, and piece
of copy is written for them — not a generic wellness app, and not (yet) the
caregiver side, which is main-challenge scope.

## Approach and logic

1. **Check-in** — 3 real screening questions adapted from the WHO ASSIST
   (Alcohol, Smoking and Substance Involvement Screening Test) instrument,
   plus one open field for the person's own words about their trigger and
   their reason to stay clear. See `lib/data/assist-lite.ts`.
2. **Script generation** (`/api/generate-script`) — the check-in answers are
   sent to Gemini (`gemini-2.5-flash`), which drafts a short, personal,
   WRAP-style ("Wellness Recovery Action Plan") emergency script: their
   trigger, their own reason to stay clear, and one grounding action. A real
   national helpline number is appended programmatically (never generated by
   the model, to guarantee accuracy).
3. **"I need help right now"** (`/api/crisis-response`) — the saved script is
   sent back to Gemini with a "this is happening right now" framing, and
   Gemini reads it back conversationally, closing the loop.

This is a real, non-mocked closed loop: real screening input -> real Gemini
call -> persisted personal output -> real Gemini call reusing that output ->
real helpline data. Nothing in this path is hardcoded/faked.

## How it works (running locally)

```bash
npm install
cp .env.example .env.local   # then paste a free key from https://aistudio.google.com/apikey
npm run dev
```

Open http://localhost:3000, walk through Start check-in -> answer the
questions -> Generate my script -> I need help right now.

## Assumptions made (Step 1 scope)

- **No auth, no database.** The generated script is kept in the browser's
  `localStorage` only. Explicitly deferred to the main challenge: Firebase
  Auth (anonymous), Firestore persistence.
- **Typed check-in, not voice-first.** The problem statement asks for
  "zero-typing interventions" — Step 1 proves the AI/decision pipeline is
  real end-to-end; the Gemini Live API voice layer is main-challenge scope.
- **Simplified ASSIST scoring**, not the official multi-branch WHO algorithm
  (documented in `lib/data/assist-lite.ts`) — flagged for replacement with
  the full official scoring in the main challenge.
- **Single persona (person in recovery).** The caregiver flow, the
  non-punitive streak/milestone system, and Google Places-based facility
  lookup are all designed (see project research docs) but not built in
  Step 1.
- **One helpline surfaced** (National Toll-Free Drug De-Addiction Helpline,
  1800-11-0031) for simplicity; Tele-MANAS is in `lib/data/helplines.ts`
  ready to surface in the main challenge.

## Known upstream issue

`npm audit` reports 12 high-severity advisories, all inside Next.js
16.2.11's own bundled build-time dependencies (postcss, sharp, the
eslint/minimatch chain) — not exploitable via this app's runtime/user-facing
surface, and Next has not shipped a patched release yet. `npm audit fix
--force` would downgrade to Next 9.3.3, which is not a real fix. Tracking
upstream for a patched Next release rather than downgrading.

## Deploying (Firebase App Hosting)

```bash
firebase init apphosting   # link to the GitHub repo, connect the Firebase project
firebase apphosting:secrets:set GEMINI_API_KEY
git push origin main       # App Hosting auto-deploys on push
```

Next.js 16 (App Router, TypeScript, Tailwind) · `@google/genai` (server-side
